# Recruitment Form
## Demo link 
https://riteshthesharma.github.io/form/ 
## About this project 
This is a recruitment form project which helps recruiters to see the candidate's information and let candidate fill his/her information to be recieved by recruiter. It alerts the candidate if he/she skips any field before moving to next section of form or submitting it. After submission he/she can see the information he/she filled and can go back to edit any information or can give more responses.

# Setup / Installation 
Node version: v14.15.3
npm version: 6.14.9

Clone this repo:

>>  git clone https://github.com/g-czajk/Order-form.git

Go to the project directory:

>> cd form

Install dependencies:
>> npm install

Start dev server:
>> npm start
